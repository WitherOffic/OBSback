# Разработка OBSback

`app/` содержит Windows PowerShell 5.1-совместимый движок OBS Full Clone Tool и меню OBSback. `settings/` содержит только шаблоны настроек без личных путей. Скрипты PowerShell сохраняются в UTF-8 с BOM, BAT — без BOM и с CRLF.

Самопроверка по умолчанию запускает полный набор тестов в дочернем PowerShell и сохраняет stdout/stderr в `%LOCALAPPDATA%\OBSback\Logs\self-test.log`. На экран выводятся две строки при успехе или причина и путь к логу при ошибке. Параметр `-Detailed` оставляет полный вывод в консоли. Сборка проверяет короткий вывод, содержимое лога и блокировку бекапа при отсутствующем файле движка; тестовые логи создаются только во временной папке сборки.

`Get-ObsBackToolLayout` разделяет корень приложения, служебных файлов и настроек. Самостоятельный движок в распакованном бекапе сохраняет прежнее плоское расположение. Создание бекапа берёт файлы восстановления из `app/`, не добавляет меню и старые отчёты разработки. Restore сохраняет совместимость с метаданными прежних архивов.

`tools/Build.ps1` запускает самопроверку в Windows PowerShell 5.1, собирает пакет по явному списку, распаковывает его и повторно проверяет запуск из пути с пробелами и кириллицей. Каждый элемент ZIP сверяется по SHA-256 с исходником. Тесты используют временные файлы; обнаружение и остановка OBS моделируются. Реальные процессы OBS и пользовательские конфигурации не меняются.

Существующие тесты покрывают планирование копирования, целостность пакета, пути и reparse points, выбор установки, фильтрацию штатных секретов, сохранение полного снимка при выборе Y, удаление распакованной копии только после проверки ZIP и обработку ошибок.

Перед распространением изменений движка дополнительно проверяйте полный цикл на отдельной тестовой установке OBS. Автотесты не проверяют работу каждого плагина и переносимость авторизации сторонних сервисов.
