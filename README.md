# OBSback

Перенесите свой OBS на другой Windows-ПК: сцены, профили, плагины и локальные медиа в одном бекапе.

**[Скачать последнюю версию](https://github.com/WitherOffic/OBSback/releases/latest)** · [История изменений](CHANGELOG.md) · [Сообщить о проблеме](https://github.com/WitherOffic/OBSback/issues)

## Начало работы

1. Скачайте **OBSback-v1.3.1.zip** из раздела Releases и распакуйте целиком.
2. Запустите **OBSback.bat**.
3. Выберите создание, восстановление или проверку бекапа.

В папке загруженного инструмента всего четыре элемента:

```text
OBSback.bat     ← запуск
README.txt     ← короткая инструкция
settings/      ← необязательные настройки
app/           ← служебные скрипты
```

Требуется Windows с Windows PowerShell 5.1. Для восстановления нужны права администратора. Репозиторий содержит дополнительные материалы для разработки; готовый компактный пакет находится в Releases.

## Что сохраняется

- Сцены и профили OBS, файлы выбранной установки, найденные плагины и локальные ресурсы.
- Выбор между Steam, обычной и Portable-установкой: видны версия, путь, конфигурация и статус запуска. Нестандартный путь можно указать вручную.
- Проверка файлов по SHA-256, отчёт об источниках и внешних зависимостях.
- Самостоятельный комплект восстановления внутри каждого бекапа.

Steam и обычная OBS могут использовать один `%APPDATA%\obs-studio`. Перед копированием инструмент учитывает процессы с общей конфигурацией. Веб-ресурсы остаются внешними зависимостями; Teleport намеренно исключён.

## Данные аккаунтов — на ваш выбор

Перед созданием бекапа появляется вопрос:

```text
Копировать данные входа в аккаунты и ключи трансляций? Y/N [N]
```

**N или Enter** исключает штатные данные авторизации OBS, ключи трансляции и браузерные сессии. После восстановления потребуется войти заново и настроить подключение. Для нестандартного сервиса сбрасываются его настройки подключения, поскольку секрет может быть частью адреса сервера.

**Y** сохраняет данные подключений в составе полного снимка. Перенос сохранённой сессии не гарантирует вход на другом ПК: сервис может потребовать повторную авторизацию.

Этот выбор не очищает произвольные секреты из сторонних плагинов и URL источников. Личный бекап не предназначен для публикации на GitHub.

## Где найти результат

По умолчанию — `%USERPROFILE%\OBSBackup`. Путь можно изменить в `settings/BACKUP_DESTINATION.txt`.

После успешного создания и проверки ZIP инструмент удаляет свою распакованную рабочую копию и открывает Проводник с выделенным архивом. Рядом остаётся файл `.sha256`. При ошибке упаковки или проверки папка с бекапом сохраняется.

## Восстановление

1. Распакуйте ZIP бекапа.
2. Запустите `RESTORE_OBS.bat` из распакованной папки либо выберите восстановление в меню OBSback.
3. Выберите целевую установку OBS и следуйте подсказкам.

Формат бекапов ветки 1.x сохранён. Старые архивы не нужно перепаковывать. Проверка целостности выполняется перед изменениями; механизм отката прежней версии сохранён.

## Проверка и разработка

Самопроверка в меню и перед бекапом показывает только короткий статус и итог.
Подробности последнего запуска сохраняются в `%LOCALAPPDATA%\OBSback\Logs\self-test.log`.
При ошибке на экране будут причина и путь к логу; создание бекапа останавливается.
Полный вывод доступен разработчикам через `app/SelfTest-ObsClone.ps1 -Detailed`.

Для сборки из исходников:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build.ps1
```

Сборка запускает тесты на временных данных, проверяет компактный пакет и каждый файл ZIP. Результаты появляются в `dist/`. Эти проверки не заменяют восстановление на реальном тестовом ПК и не проверяют совместимость всех сторонних плагинов.

OBSback продолжает OBS Full Clone Tool v1.1.0. [Подробнее об устройстве и проверках](docs/DEVELOPMENT.md).
