# История изменений

## 1.3.0 — 2026-09-09

- Название проекта — OBSback, единый запуск через OBSback.bat.
- Меню создания, восстановления, проверки бекапа и самопроверки.
- Служебные файлы перенесены в app, настройки — в settings.
- В готовой поставке четыре элемента в корне; длинные старые отчёты исключены из пакета.
- Проверку можно запустить из меню с указанием распакованного бекапа.
- Сохранены формат бекапов 1.x и прежние механизмы восстановления.
- Добавлены страница проекта и воспроизводимая процедура сборки с проверкой ZIP.

## 1.2.0 — 2026-09-08

- Вопрос о включении данных аккаунтов перед бекапом; по умолчанию они исключаются.
- Фильтрация штатных данных входа OBS, ключей трансляций и браузерных сессий в копии.
- После успешной проверки ZIP удаляется распакованная рабочая копия бекапа.
- Проводник открывает папку с выделенным готовым ZIP.
- Ошибки упаковки и проверки сохраняют папку для восстановления результата.

## 1.1.1 — 2026-09-08

- Ручной выбор пути доступен и при одной найденной установке OBS.
- Исправлено определение Portable по оставшейся папке config.
- Поддержаны старые манифесты без поля типа установки.

## 1.1.0 — исходный пакет

- Выбор Steam, Standard и Portable с версией, путём и статусом запуска.
- Учёт общей конфигурации нескольких установок OBS.
